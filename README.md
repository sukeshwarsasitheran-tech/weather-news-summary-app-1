# Daylight — Weather & World Brief

A responsive, static HTML/CSS/JavaScript demo that combines a local weather snapshot, a short daily briefing, world-news summaries, and recent-event context.

## Run it

Open `index.html` in a browser. No build step or dependencies are required. The Google Fonts import is optional; the page falls back to system sans-serif fonts if offline.

## Demo features

- Sample weather and four-day outlook for San Francisco, New York, London, Tokyo, Paris, and Sydney
- City search with a helpful message for cities not included in the sample data
- Daily summary and a practical weather heads-up
- World news cards and recent-event summaries (all fictional/sample copy)
- Refresh button to rotate the order of the sample stories
- Light/dark theme toggle
- Responsive layout and reduced-motion support

## Data note

All forecast, news, and event information is placeholder sample data. The app does not fetch live weather, news, or AI-generated summaries.
